# Turbo Gold Hits 1

Website for Turbo Gold Hits 1, three games on one tape: Dandy Driveby Shooters, Hesari Gauntlet and Kruunuvuorensilta Track & Field.

Static site served by GitHub Pages from the root of `main`. Preview locally with `python3 -m http.server` and open http://localhost:8000.

- `index.html`, `style.css`, `main.js`: the page
- `assets/`: font, logo, boxes, loading screens, stills
- `media/promo_720p.mp4`: the promo video
